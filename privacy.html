Privacy Policy

FCC PR Summary — fcc-prs.github.io

This site publishes a weekly summary of pull requests merged in the FCC and Key4hep software ecosystems. This policy describes how the site's automated tooling handles data.

Data collected

The site does not collect personal data from visitors. No cookies, analytics, or tracking scripts are used.

The automated workflow that creates weekly Google Docs drafts uses an OAuth token to authenticate with Google on behalf of the site owner. That token is stored as a private secret and is not shared with third parties.

Google API usage

The site uses the Google Docs and Google Drive APIs solely to create weekly draft documents shared with a small group of editors. No data from Google accounts other than the authorized account is accessed or stored.

Third-party services

Pull request data is fetched from the GitHub API. Meeting information is fetched from Indico (CERN). Neither service receives personal data from visitors to this site.
